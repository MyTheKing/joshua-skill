# Joshua Skill

[简体中文](README.md) · **English**

Joshua Skill is an open-source collection of agent skills. Each group has its own directory, installation guide, and downloads.

## Skill catalog

| Skill group | What it does | Version |
| --- | --- | --- |
| [Codex ↔ Claude Code bridge](skills/codex-claude-bridge/README.en.md) | Pass tasks between agents in the same project to read code, review changes, or edit files with your permission. | [v0.1.0](https://github.com/MyTheKing/joshua-skill/releases/tag/v0.1.0) |

I'll keep sharing skills I use in real projects so you can download them and use them in your own work. Test orchestration is the next group planned for the catalog.

If these skills help you, please leave a ⭐ Star to support the project and find future updates.
