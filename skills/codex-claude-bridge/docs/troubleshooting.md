# 常见问题

[返回目录](../README.md#目录) · [安装](install.md) · [用法](usage.md)

| 情况 | 排查方法 |
| --- | --- |
| 找不到技能 | 确认解压到了项目根目录，隐藏路径与[安装表](install.md#从-zip-导入项目)一致。信任项目后，新建会话再试。 |
| 找不到 `claude`、`codex` 或 `python3` | 在启动发起端的环境检查命令是否位于 `PATH`。更新 CLI 后重新启动宿主。 |
| 接收端要求登录 | 在本机直接启动对应 CLI，完成官方登录流程后重试。 |
| 发起端报告权限被拒 | 看具体被拦截的命令、读写路径或网络权限。有必要时按宿主提示授权这次任务。 |
| Claude 后台任务没有立即回结果 | 用 `threadId` 查询 `claude_result`。检查返回状态、权限拒绝和 `stderrPath`。 |
| Claude 的交互式历史找不到后台会话 | 在原项目目录运行桥接返回的 `claude --resume <threadId>`。要让桥接再续跑，请先退出该交互会话。 |
| Codex 返回模型不可用 | 检查账号支持的模型，按 Claude 端脚本的 `--model` 用法明确指定。 |
| 调试端口连不上 | 回到 CLI 联动，或检查[桌面配置](../claude/skills/codex-app-bridge/desktop.md)里的前置条件。 |
| 提示递归调用被阻止 | 在当前发起端直接完成任务，或由用户从另一个独立会话发起新任务。 |

Codex → Claude Code 的后台记录默认在 `~/.codex/claude-bridge/`。记录含任务提示词和运行输出。若有保密要求，委派前先确认可共享的文件和数据。
