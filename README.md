# Joshua Skill

Joshua Skill 是一个开源 Skill 仓库。每组 Skill 都有自己的目录、安装说明和下载入口，可以按需选择。

## Skill 目录

| Skill | 用途 | 版本 |
| --- | --- | --- |
| [Codex ↔ Claude Code 联动](skills/codex-claude-bridge/) | 在同一个项目里互相发任务、读代码、复核或按授权改文件。 | [v0.1.0](https://github.com/MyTheKing/joshua-skill/releases/tag/v0.1.0) |

测试编排 Skill 整理后会单独收录。

如果这些 Skill 帮到了你，欢迎点一下仓库右上角的 ⭐ Star 支持项目。
